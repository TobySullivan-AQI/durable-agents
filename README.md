# durable-agents

An APM package of durable-agent identity and persistence instructions.

From the root of your repository, initialize APM if you do not already have an `apm.yml`:

```sh
apm init
```

Add and install the package, then compile the instructions for your agent:

```sh
apm install TobySullivan-AQI/durable-agents
apm compile
```

The install command adds the package to your `apm.yml`. In an existing checkout where the dependency is already declared, run `apm install` to restore it before `apm compile`.

## What's included

- **Instruction `durable-agent`:** the agent's identity and persistence rules. It keeps knowledge, practices, work, status and decisions in the repository across sessions.
- **Skill `editing-root-context`:** how the agent changes its own instructions, rules and skills. These files are generated by APM, so the agent edits the sources under `.apm/` and runs `apm install` and `apm compile --clean`. It never edits generated or package-deployed files. A change to this package's own text goes to the user as a proposal.

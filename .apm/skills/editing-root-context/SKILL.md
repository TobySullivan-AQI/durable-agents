# Edit root context through APM

Your repository uses APM (Agent Package Manager). `apm.yml` is the source of truth. APM generates the files that agents load. If you edit a generated file directly, the next `apm install` or `apm compile` overwrites your change. A changed package file also no longer matches its hash in `apm.lock.yaml`.

## Find the source of a file

1. Read `apm.lock.yaml`. Each dependency lists its `deployed_files`. A file in that list belongs to that package. **Do not edit it.** Example: `.claude/rules/durable-agent.md` comes from the `durable-agents` repository on Github.
2. A file deployed from the repository itself comes from `.apm/`:
   - `.claude/rules/<name>.md` and `.github/instructions/<name>.instructions.md` come from `.apm/instructions/<name>.instructions.md`.
   - `.claude/skills/<name>/` and `.agents/skills/<name>/` come from `.apm/skills/<name>/`.
3. `apm compile` writes `AGENTS.md`, `.github/copilot-instructions.md` and, with some targets and versions, `CLAUDE.md`. These files start with a "Generated by APM CLI" comment. Do not edit them.

If you can't find the source of a file, ask the user before you edit it.

## Change a local instruction or skill

1. Edit or add the source file:
   - Instruction: `.apm/instructions/<name>.instructions.md`, with `description` frontmatter.
   - Skill: `.apm/skills/<name>/SKILL.md`. The `name` must match the directory.
2. Do not contradict a package's instructions. Add to them. Example: a package says "read `work/status.md` first". A local instruction can say "read `work/handoff.md` before `work/status.md`".
3. For a new skill, run `apm audit --file .apm/skills/<name>/SKILL.md`.
4. Deploy and compile:
   ```bash
   apm install          # deploys package and local files for each target; updates apm.lock.yaml
   apm compile --clean  # regenerates compiled files; removes outputs that are no longer generated
   ```
   With the `claude` target, recent APM versions don't generate `CLAUDE.md` when the instructions are in `.claude/rules/`. `--clean` then removes a stale `CLAUDE.md`. This is expected.
5. Commit the source files and the generated files together.

## Change a package's instructions

Do not edit the deployed copy. The package lives in its own repository. Propose the change to the user, and change the package repository only with their approval. Until then, add a local instruction that extends the package's rule. After the package changes, run `apm install` to update the deployed copy.

## Know when a change takes effect

Agents load rules and skills when a session starts. A change takes effect in the next session, not the current one.
